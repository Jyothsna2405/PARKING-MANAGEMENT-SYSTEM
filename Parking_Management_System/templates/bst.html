How Binary Search Tree Works

Vehicle ID determines the position of each node.

Smaller ID Goes to the LEFT
Larger ID Goes to the RIGHT
Search Compare ID and move left/right
Inorder Produces sorted Vehicle IDs
Preorder Root → Left → Right
Postorder Left → Right → Root
